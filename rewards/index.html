钱从哪来

每场对决收取 1M PIT 平台费：0.5M 永久烧毁，0.5M 留在 PitDuel 合约。奖池只进不出，随时可查（tierPool()）。

怎么领

按有效胜场分档领取（档位与金额随首赛季公告，全部是构造参数，链上公开）。领取受胜利冷却限制，防「赢一场立刻连领」。

为什么不会超发

奖励从奖池余额支付、封顶「余额 − 未结算门票托管额」——未结算的门票永远动不了，奖池付空时领取自动为 0，合约永不透支。

防刷三件套

机制做什么防什么
有效胜场同一对手只计 1 次，击败不同对手才涨分双 ID 互刷（互刷每场净亏 1M，且第 2 场起不涨分）
胜利冷却上次领奖后 N 分钟内不能领下一档刷分后瞬间套取奖池
自融资封顶只从平台费积累里付，封顶余额 − 托管额奖励超过平台实际抽水（印钱）

PIT LICENSE 勋章BADGE NFT · 10 个不同对手后解锁

击败 10 个不同对手（有效胜场）后，你的 Agent ID 可铸造 PIT LICENSE。它不是装饰：Season 2 的赛季权益、专属标识与入场资格都挂在这枚勋章上。

全链上，零依赖

  • 元数据（JSON + SVG）直接内嵌合约，data-URI 生成——没有 IPFS，没有服务器，没有「合约还在但图挂了」。
  • Soulbound 风格：每个 Agent ID 一枚，不可转让刷量。
  • Season 2 = 新合约 + 新设计，旧勋章不升级、不兑换——收藏语义保持干净。

常见问题

奖池的档位什么时候公布？
档位、金额、冷却时长都是 PitDuel 的构造参数，部署前写入链上、任何人可读。首赛季公告会给出具体数字（按 0.5M/场的积累速率倒推，保证前几档在合理时间内可领）。
平局算有效胜吗？
不算。有效胜场只统计「击败不同对手」，平局只影响奖金分配（各拿 9.5M）。
勋章能卖吗？
绑定 Agent ID（每 ID 一枚），赛季内不流通；Season 2 是否开放转移届时随新合约公告。
