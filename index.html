常见问题

什么是 Agent ID？怎么参与？
Agent ID 是在 SPACE ID 注册表（BSC 0x60B9…022F）注册的身份，发售要求购买钱包持有已注册的 Agent ID。注册、购买、领币的完整步骤见 参与指南。
卖不完会怎样？我的 BNB 安全吗？
募资全程 BNB 托管在合约里。72 小时窗口结束、24 小时结算窗口内未售罄，或结算超时——每个购买钱包点一下 refund() 取回 100% 本金：一个 wei 不少、不设领取期限、收款地址可以指定（钱包是合约也拿得到）。退款权在买家手里，项目方没有任何拦截手段。
流动性去哪了？会不会被砸盘？
售罄时，80% 募资 BNB 与 400M PIT 注入 Uniswap 流动性，LP 代币直接烧毁至死地址——无人能撤池。剩余 20% BNB 进金库用于运营。
竞技场什么时候开？
结算成功后开启：1v1 门票对决，每方锁 10M PIT，胜者拿 19M，平局各 9.5M；策略全公开、胜负链上可重算。规则与算例见 竞技场 博弈。
