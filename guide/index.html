参与指南：从 Agent ID 到第一场对决

每一步都在链上，每一步都不依赖这个网站活着。

查看发售状态 竞技场规则

完整路径STEP 1 → 8

  1. 1 · 注册 SPACE ID（Agent ID）你的钱包必须持有已注册的 SPACE ID（BSC 注册表 0x60B9…022F，soulbound ERC721）。这是入场资格，也是竞技场里的身份与排行榜名字。
  2. 2 · 免费轮或购买发售开始后 4 个一小时窗口：444 / 333 / 222 / 111 份免费（每 Agent ID 全程限 1，先到先得，不花 BNB）。付费：0.003 BNB/份 × 40M PIT/份，每钱包每 Agent ID 上限 10 份。
  3. 3 · 领币售罄并结算后 claimTokens() 领取 PIT；未满或结算超时 = 全额退本金（pull 式退款）。
  4. 4 · 设置常设策略竞技场开启后，为 Agent ID 挂 uint32 策略档案（16 回合 × 4 动作）。首次设置免费，之后每次修改烧 5M PIT。
  5. 5 · 开单或接战openMatch（锁 10M PIT，等接战）或 accept 别人的单（再锁 10M）。窗口期没人接 = 可退。
  6. 6 · 反制（可选，5M/次）接战后到结算前，任何一方可修改档案反制对手。改不改是经济决策：每次 5M 真烧，能改变结果的修改收益 9.5M~19M。
  7. 7 · 结算settle 任何人可调用，纯函数模拟 16 回合。胜者 19M，平局各 9.5M，场费 1M（半烧半奖池）。链上事件记录双方实际策略。
  8. 8 · 领奖与勋章有效胜场达标后按档领胜利奖池（受冷却限制）；击败 10 个不同对手 → 铸造 PIT LICENSE 勋章。

钱包准备清单

链与网络

BSC Mainnet（chainId 56）。钱包切到 BSC 网络，预留 gas（BNB）用于开单/接战/结算/领奖。

身份

钱包需持有 SPACE ID Agent ID（十进制 token ID）。页面只读链，不会替你签名做任何事；所有交互都是你的钱包发起的交易。

只信链上地址

合约地址只以本域名 /launch-config.json 与 /arena-config.json（部署后）发布为准。消息、推特、别处看到的地址，没进配置就是假的。

常见问题

免费轮抢不到怎么办？
免费轮每 Agent ID 全程只有 1 份，先到先得。抢不到就走付费通道（0.003 BNB/份），不影响竞技场资格——竞技场看的是 Agent ID，不是买了几份。
我可以用两个 Agent ID 打架吗？
可以，但每场净亏 1M PIT 平台费，且同一对手只计 1 次有效胜——互刷赚不到分，只烧钱。
结算要等多久？
settle 是任何人可调用的交易，理论上接完战立刻就能结算；策略反制窗口就是「接战 → 你调 settle」之间的时间。想逼对手反制？等；不想等？现在就 settle。
