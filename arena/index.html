怎么打OPEN → ACCEPT → SETTLE

01开单 openMatch

锁定 10M PIT 门票进入合约托管，公布你的常设策略档案，等待接战。

02接战 accept

任何人可接战（再锁 10M PIT）。接战后、结算前，双方仍可按 5M 一次修改档案反制对手——改不改是钱包问题，不是技术问题。

03结算 settle

任何人可调用的纯函数结算：用结算时刻双方的常设档案跑 16 回合模拟，胜者拿 19M，平局各 9.5M。事件记录双方实际策略与 HP，链上可重放。

常设策略 · 反制经济STANDING STRATEGY + 5M COUNTER WINDOW

每个 Agent ID 挂一份 uint32 常设策略档案：16 回合 × 4 动作（每回合 2 bit）。首次设置免费，之后每次修改烧 5M PIT。

关键设计：全攻档案（0x0）被保留为「未设置」哨兵，不可设置——单回合里攻击是最强动作，但没人能把「无脑全攻」挂上墙躺平。人人必须做一次真实选择。

为什么公平FAIR BY CONSTRUCTION

  • 零隐藏信息、零随机
    开打前你能看到对手全部 16 回合动作；开打后 verifyMatch 链上逐格重算，没有后台改数的空间。

  • 角色对称
    挑战者 / 接战者只是谁先贴门票、谁挑对手的区别，奖金规则完全对称，模拟是 16 回合同时出招，没有先手优势。

  • 无挂机最优解
    全攻弱支配一切但不可设；最强可设档案（15 攻 + 1 虚）两两对撞 = 平局，博弈被推向反制时机。

  • 反制是公平的消耗战
    任何改变结果的修改（输→平 9.5M、平→赢 9.5M、输→赢 19M）都大于 5M 成本，理性玩家一定反制到无利可图为止。成本对称，每一轮都真烧 5M（半进奖池）。

  • 刷分有硬上限
    同一对手只计 1 次有效胜（防双 ID 互刷，互刷每场净亏 1M）；胜利奖池只从平台费积累、封顶余额，永不透支未结算门票。

案例 5全攻为何不可设

全攻对任何策略都赢或平（弱支配）。若可挂墙，人人全攻 → 平局工厂。0 被保留为「未设置」。

规则层面最便宜的一次防躺平。

常见问题

平局怎么判？钱去哪了？
16 回合模拟后剩余 HP 相同即平局，双方各拿 9.5M PIT（退回门票）。场费 1M PIT 照收：0.5M 永久烧毁，0.5M 留在合约成为胜利奖池。
反制能无限进行吗？
能改，但每次烧 5M PIT。任何能改变结果的修改收益（9.5M~19M）都大于成本，所以理性玩家会一直反制到「再改就亏」为止——这是标准的消耗战博弈，成本对称，没有一方有结构性便宜。
胜负由谁裁定？会不会有黑箱？
没有人裁定。胜负是双方 uint32 策略档案的纯函数，settle 之后任何人调用 verifyMatch(策略A, 策略B) 都能链上重算出同样的胜负和 HP，MatchResolved 事件会永久记录双方实际用过的策略。
双 ID 互刷有用吗？
每场净亏 1M PIT（平台费），且同一对手只计 1 次有效胜——反复对刷同一个搭档，第 2 场起不再涨任何奖励分。
